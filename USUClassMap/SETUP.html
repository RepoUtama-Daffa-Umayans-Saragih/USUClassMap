Bagian 1

Daftar Software yang Dibutuhkan

Pastikan semua software berikut terinstal sebelum memulai

# Software Versi Min. Status Fungsi
1 PHP 8.2+ Wajib Runtime backend Laravel
2 Composer 2.x Wajib Package manager PHP (install Laravel, EasyRdf, dll)
3 Node.js 18+ Wajib Build frontend (Vite, Tailwind CSS)
4 npm 9+ Wajib Package manager JS, sudah termasuk di Node.js
5 Git Terbaru Wajib Clone repository proyek
6 SQLite 3.x Wajib Database default (biasanya sudah bawaan PHP)
7 Apache Jena Fuseki 4.x+ Opsional Triplestore untuk fitur SPARQL Semantic Web
ℹ️ Catatan Fuseki: Jika Fuseki tidak diinstal, aplikasi tetap berjalan normal menggunakan fallback otomatis ke MySQL/SQLite. Fuseki hanya diperlukan untuk mengaktifkan fitur pencarian SPARQL penuh.

Bagian 2

Cara Install Software

Panduan instalasi yang disesuaikan dengan kebutuhan proyek ini

🐘
PHP 8.2+
Verifikasi: php -v

Windows: Download dari windows.php.net/download (pilih versi Thread Safe). Ekstrak ke C:\php, tambahkan ke PATH. Lalu aktifkan ekstensi berikut di php.ini:

php.ini — hapus tanda titik koma (;) di depan baris berikut
extension=curl extension=fileinfo extension=mbstring extension=openssl extension=pdo_sqlite extension=sqlite3 extension=zip extension=gd
Linux / Ubuntu
sudo apt update sudo apt install php8.2 php8.2-cli php8.2-curl php8.2-mbstring \ php8.2-xml php8.2-zip php8.2-sqlite3 php8.2-gd
🎵
Composer 2.x
Verifikasi: composer -V

Windows: Download installer .exe dari getcomposer.org/download dan jalankan wizard instalasi.

Linux / macOS
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');" php composer-setup.php sudo mv composer.phar /usr/local/bin/composer
💚
Node.js 18+ & npm
Verifikasi: node -v & npm -v

Download installer LTS dari nodejs.org (npm sudah termasuk di dalamnya). Ikuti wizard instalasi — tidak ada konfigurasi tambahan.

🗄️
SQLite — Buat File Database Kosong
Ini adalah langkah khusus proyek, bukan instalasi software baru
Windows (CMD) — jalankan dari folder USUClassMap
REM Buat file database kosong type nul > database\database.sqlite
Linux / macOS
touch database/database.sqlite
🔗
Apache Jena Fuseki Opsional
Hanya jika ingin mengaktifkan fitur SPARQL
  1. Download dari jena.apache.org/download
  2. Ekstrak arsip ke folder yang diinginkan
  3. Jalankan Fuseki dengan perintah berikut:
Jalankan Fuseki (dari folder hasil ekstrak)
# Windows fuseki-server.bat --update --mem /usuclassmap # Linux / macOS ./fuseki-server --update --mem /usuclassmap
Langkah selanjutnya: Buka http://localhost:3030, pilih dataset usuclassmap, lalu upload file storage/app/rdf/schedules.rdf.
🚀
Bagian 3

Tahapan Menjalankan Proyek

Ikuti langkah-langkah ini secara berurutan

⚠️ Penting — Lokasi Folder!
Semua perintah di bawah ini dijalankan dari dalam folder proyek:
d:\Documents\TUBES WEB SEMANTIK\Kelompok 3 Web Semantik\USUClassMap\

Buka terminal / Command Prompt, lalu ketik:
cd "d:\Documents\TUBES WEB SEMANTIK\Kelompok 3 Web Semantik\USUClassMap"
1
Clone Repository
Unduh kode sumber proyek dari Git. Lewati langkah ini jika sudah punya folder proyeknya.
git clone <URL_REPOSITORY> USUClassMap cd "d:\Documents\TUBES WEB SEMANTIK\Kelompok 3 Web Semantik\USUClassMap"
2
Install Dependensi PHP (Backend)
Mengunduh semua library PHP termasuk Laravel 11, EasyRdf, Maatwebsite Excel, dan lainnya.
📂 d:\...\USUClassMap\
composer install
3
Install Dependensi JavaScript (Frontend)
Mengunduh Tailwind CSS v4, Alpine.js, Vite, dan Axios.
📂 d:\...\USUClassMap\
npm install
4
Buat File Environment (.env)
Salin file contoh konfigurasi, lalu generate Application Key secara otomatis.
📂 d:\...\USUClassMap\ — Windows CMD
REM Salin file env copy .env.example .env REM Generate application key php artisan key:generate
5
Konfigurasi File .env
Buka file .env dengan teks editor, pastikan baris-baris penting berikut sudah benar:
📄 .env — Konfigurasi Penting
# Nama aplikasi dan URL APP_NAME="USUClassMap" APP_TIMEZONE=Asia/Jakarta # Database SQLite (default, tidak perlu diubah) DB_CONNECTION=sqlite # Queue untuk job regenerasi RDF otomatis QUEUE_CONNECTION=database # Fuseki SPARQL (opsional — hapus # jika pakai Fuseki) # SPARQL_ENDPOINT=http://localhost:3030/usuclassmap/query
6
Buat File Database SQLite
Laravel membutuhkan file database.sqlite yang sudah ada sebelum migrasi bisa dijalankan.
📂 d:\...\USUClassMap\ — Windows CMD
type nul > database\database.sqlite
7
Jalankan Migrasi Database
Membuat semua tabel di database: users, buildings, rooms, lecturers, courses, schedules, room_media, jobs, cache, dll.
📂 d:\...\USUClassMap\
php artisan migrate
8
Jalankan Seeder (Data Awal)
Mengisi database dengan data awal: akun admin, gedung USU (dengan koordinat), ruangan, dosen, mata kuliah, jadwal, dan 100 data dummy FIB.
📂 d:\...\USUClassMap\
php artisan db:seed
9
Buat Storage Symlink
Membuat link dari public/storage ke storage/app/public. Tanpa ini, foto 360° tidak akan muncul!
📂 d:\...\USUClassMap\
php artisan storage:link
⚠️ WAJIB dijalankan sekali! Jika dilewati, semua foto ruangan dan media 360° tidak akan bisa diakses via URL browser.
10
Generate File RDF Opsional
Membuat file storage/app/rdf/schedules.rdf. Diperlukan jika menggunakan Apache Jena Fuseki.
📂 d:\...\USUClassMap\
php artisan rdf:generate
11
Build Aset Frontend
Kompilasi Tailwind CSS dan JavaScript menggunakan Vite.
📂 d:\...\USUClassMap\ — Pilih salah satu
# Development (dengan hot-reload, tetap berjalan di background) npm run dev # ATAU: Production (sekali build, hasilkan file statis) npm run build
12
Jalankan Web Server Laravel
Buka terminal baru (jangan tutup terminal npm run dev), lalu jalankan:
📂 d:\...\USUClassMap\ — Terminal Baru
php artisan serve
✅ Aplikasi akan berjalan di: http://localhost:8000
13
Jalankan Queue Worker
Diperlukan agar job regenerasi RDF berjalan otomatis saat data jadwal berubah. Buka terminal ketiga:
📂 d:\...\USUClassMap\ — Terminal Ketiga
php artisan queue:listen --tries=1
⚡ Cara Cepat — Jalankan Semua Sekaligus
Sebagai alternatif langkah 11–13, gunakan satu perintah berikut yang menjalankan semua service secara paralel:
📂 d:\...\USUClassMap\
composer dev
Perintah ini menjalankan: php artisan serve + queue:listen + pail (log viewer) + npm run dev secara bersamaan.
✅
